# 通用编码开发 harness 模板

用于将需求收集、设计、开发、测试、知识沉淀和成果复用保存在可恢复的项目工作区。支持多个业务仓库，不预设技术栈和业务模块。

1. 将本目录复制到新项目工作区，保留本模板供下次复用。
2. 填写[项目上下文](项目管理/项目上下文.md)：真实仓库路径、职责、启动/验证入口、环境与项目约束；秘密值不写文档。
3. 按[提示词速查](提示词速查.md)使用：需求# → 方案# → 新任务# → 新聊天执行# → 测试# → 任务完成#。
4. 需要跳过未完成验证/规划时由用户输入强制完成#；只登记实际交付及真实限制。

```text
harness/
├── AGENTS.md
├── README.md
├── 提示词速查.md
├── 项目管理/                 # 上下文、进度、需求基线
├── 规则/
│   ├── task-unit-actions/     # 按动作加载references，assets是输出模板
│   └── code-skill-self/       # 个人编码偏好
├── 阶段/
│   ├── S01-需求与范围/        # IDEA卡＋阶段说明/进度
│   ├── S02-方案与设计/        # PLAN卡＋阶段说明/进度
│   └── S03-功能开发/          # S03-T编号-名称/任务.md，触发后才生成
├── 知识/
│   ├── 项目分析/
│   └── 任务分析/
└── 索引/
    ├── README.md
    ├── 任务完成结果/
    └── 调研结果/
```

模板没有占位业务任务、需求、方案、历史聊天或成果；初始计数为0。目录中的assets是生成模板，不计项目任务。旧项目迁入时按实际任务登记，IDEA/PLAN不计入任务分母。

- [工程经验与适用边界](规则/task-unit-actions/references/工程经验与适用边界.md)：设计和实现相关场景按需参考。
- [模板提炼说明](模板提炼说明.md)：来源、保留规则、边界与验证范围。
- [使用及项目管理](项目管理/README.md)：初始化和版本规则。

本地skill由AGENTS.md引用使用，不会自动安装到用户全局skill目录；不会覆盖全局设置或其他项目。聊天、模型、归档等能力取决于宿主可用工具，无法自动处理时按规则降级为手动交接。
