# 模板提炼说明

提炼日期：2026-10-02。来源为已有多仓项目harness的现行规则、IDEA/PLAN、真实任务完成摘要、成果索引及规则维护记录。提炼是文档与流程整理，不重新证明原功能或新项目通过。

## 纳入模板的内容

| 来源经验 | 模板位置 | 处理方式 |
| --- | --- | --- |
| 显式提示词、按需读取与一次一卡 | AGENTS及task-unit-actions | 保留现行触发边界；不带旧提示词历史 |
| 需求→Spec→Plan | 需求规格与方案编制、Spec方案模板 | 同一PLAN维护规格/修改/验收，按五维设计章节 |
| S03直放目录与短摘要接续 | 开发任务分支与接续、任务模板 | 空项目启动，不预建占位任务 |
| 并行开发与共享文件 | 并行任务协作、进度规则 | 以聊天绑定任务，增量更新，不默认隔离代码 |
| 普通/强制完成、回传回执 | 任务完成与归档 | 真实交付、标识版本去重、唯一子会话安全归档 |
| 成果复用及显式登记 | 成果索引与复用 | 索引初始为空，只在对应完成动作注册 |
| 单份测试概要与证据边界 | 测试方式与记录 | 保留方法/脚本入口及概要，避免原始输出堆积 |
| 个人编写偏好 | code-skill-self | 保留中文属性/服务方法注释、实体构造、简洁实现等 |
| 基础设施、迁移、联调、算法和文件经验 | 工程经验与适用边界 | 提炼检查方法与适用条件，不绑定具体产品或业务 |

## 已排除及校正

- 不复制原项目的需求、方案、任务、代码、数据、账号、地址、提交、聊天ID、基线或完成索引。
- 不带入历史验证记录的通过结论，不携带旧目录占位任务及预建动作子目录。
- 初始化任务计数归零；IDEA/PLAN/assets不算任务。新项目自身真实记录另行建立。
- 默认新开发聊天使用GPT-6.1 Sol/low；不可用时说明实际能力，不硬写已生效。
- 调研反馈与调研完成均不自动归档聊天，速查及skill与详细规则统一。
- 创建聊天默认local；worktree遵循用户明确要求与宿主工具限制。
- 项目上下文不重复固定当前B版本，读取基线文件的当前值；恢复与进度修正不覆盖历史证据。

## 使用边界

本模板不自动安装skill或改全局配置；业务仓库与权限需在新项目登记。工具名称、模型支持和会话能力以运行时为准。工程经验按场景加载，不额外授权部署、数据删除、完整构建或消息推送。

目录、链接及skill格式检查见[验证记录](规则/task-unit-actions/references/验证记录.md)。不声称已对新项目完成真实业务或独立模型行为测试。
