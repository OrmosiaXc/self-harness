# 服务发布（B08通用能力）

仅在用户明确要求发布或输入作为行动指令的`发布#`时加载。讨论、初始化harness、修改代码及任务完成均不触发真实发布。此模板不包含任何可直接使用的项目主机、账户、目录、端口或工具链参数。

## 目标项目发布契约

首次发布前从目标项目的任务及已确认配置核对以下信息，保存安全引用和必要非敏感参数，不复制密码、私钥或令牌：

| 项目 | 需明确的信息 |
| --- | --- |
| 发布对象 | 绑定任务、服务/模块、仓库及代码范围、目标环境、产物路径 |
| 本地构建 | 运行时与构建工具、配置及依赖来源、构建命令、测试策略；不擅自跳过测试 |
| 远端访问 | 主机/连接方式、安全凭据引用、发布目录、运行账户与权限 |
| 服务控制 | 实际启停机制、目标进程/实例的唯一识别、配置与持久数据边界 |
| 校验与恢复 | 产物完整性和指纹方式、健康检查及合理等待窗口、旧版本备份/保留策略、回退方式 |

参数正文唯一保留在目标任务的发布配置段或项目既有配置文件，本参考只规定流程。使用时记录具体配置入口，不另建重复清单。已确认的参数及授权直接沿用，不重复确认；多目标有歧义或关键参数缺失时只补齐缺失信息，不猜测。发布授权不覆盖其他服务、数据库迁移、修改服务器配置或整机重启。

## 单次发布流程

1. 读取实际目标契约，核对代码版本与未提交差异，保护共享工作；按已确认构建命令生成产物。构建失败停止，不影响远端。检查产物完整性、入口、大小及指纹，避免发布旧产物。
2. 核对远端位置、资源、启停机制及目标进程归属。同名服务或目录不一致时先定位，不能误停其他实例。使用已确认的服务管理器或脚本，不擅自替换。
3. 上传到本次唯一临时位置，或使用目标平台等价的版本暂存机制；验证远端与本地指纹一致后再进入切换。上传/校验失败不停止旧服务。
4. 按目标机制停止或切换实例，确认操作结果；保留可定位的旧版本，再原子切换已校验产物。停止失败不覆盖原产物，备份不覆盖同名历史版本。
5. 启动并按目标契约检查本轮日志、目标进程/实例和健康接口；采用有界等待，不重复启动掩盖失败。成功后只按已确认保留策略清理可识别的备份/临时文件，不清理业务数据。
6. 新版本启动或检查失败时，提取必要脱敏错误摘要，按已确认策略停止新实例并回退旧版本，重新检查健康状态。自动回退最多一次；无可回退版本或回退失败立即停止并报告，不盲目重试。结果不明先核对现场再操作。

上述为文件/服务发布的参考顺序，容器或托管平台使用对应的版本切换与回退机制，保持“新版本校验后切换、失败可定位及恢复”的约束，不机械执行SSH或JAR命令。

## 记录与结果

复用绑定任务的一份发布记录，保存触发、构建和部署版本、产物指纹、执行阶段、实际运行版本、健康结果及回退摘要；同次重试更新同次记录，不复制完整日志或凭据。修改发布流程说明不表示已发布。

启动或HTTP健康通过仅证明所检查的运行状态，不等同业务验收、性能达标或任务完成。不自动建立定时发布、文件监听或监控。真实工具失败如实记录，报告实际完成与未完成步骤。
