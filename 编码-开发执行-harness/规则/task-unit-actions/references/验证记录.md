# 模板验证记录

- 日期：2026-10-02。
- 范围：两份skill格式、Markdown本地链接、目录及初始化状态、触发/接续/索引/收尾规则一致性。
- 结果：两份skill的官方quick_validate通过；全部Markdown本地文件链接有效；无占位任务、业务卡片或成果条目；源项目路径/地址/聊天标识扫描通过。
- 局限：没有为模板生成真实业务任务、调用外部服务或独立执行模型行为评测。

## 静态场景核对

| 输入/场景 | 应有行为 |
| --- | --- |
| 普通提问或讨论触发词 | 不生成动作卡/目录 |
| 需求# | 单份IDEA，不创建开发任务 |
| 方案# IDEA编号 | 单份PLAN含Spec及修改清单，不编码 |
| 新任务# PLAN编号 | 新建或复用一个任务及聊天；仅接续，除非同消息明确实施 |
| 测试# | 单份测试记录维护方法和运行概要，不默认保存完整输出 |
| 普通完成验收不足 | 保留缺口，不自动索引/归档 |
| 强制完成# | 如实登记已交付及跳过项，回传、接收回执、安全归档开发子会话 |
| 调研反馈#/调研完成# | 更新原卡；后者另登记调研索引，不自动归档聊天 |
| 工具失败/不明结果 | 保留控制字段，仅重试缺失步骤，不重复创建/累计 |
| 多任务共享记录 | 重读最新记录，增量合并，历史计数不批量替换 |

静态核对只证明文档规则能够表达这些边界，不能替代模型实测。
