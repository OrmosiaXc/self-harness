# 项目管理使用说明

项目上下文保存仓库、职责、入口、运行条件和项目约束；项目进度保存真实任务状态与活动聊天；需求基线保存用户确认的业务行为。正文各存一份，通过链接关联。

初始化先填上下文，不创建虚拟需求/任务。功能想法用需求#保存IDEA；方案#在PLAN内编制Spec与修改清单；新任务#才建S03任务。目录是路由约定，不构成动作授权。

- B0表示尚未建立确认基线；用户确认业务行为后按规则生成REQ及B版本，不能把代码存在视为需求确认。
- R/I是任务内需求/实现版本，Spec是PLAN版本；另记真实Git提交、相关未提交改动、环境与验证日期。
- 项目与阶段计数按任务.md去重；不统计IDEA、PLAN、动作卡、会话及assets模板。已取消任务排除，强制完成注明其范围与验证边界。
- 多任务以聊天绑定为准，共享文件写前重读最新行，增量合并；历史日志保留原时点计数。

规则入口：[AGENTS](../AGENTS.md)、[任务skill](../规则/task-unit-actions/SKILL.md)、[进度与阶段](../规则/task-unit-actions/references/进度与阶段.md)。
