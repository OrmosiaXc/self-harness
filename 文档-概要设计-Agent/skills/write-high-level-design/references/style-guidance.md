# 内容与样式指导

- 使用简洁、正式、可验证的中文书面语。
- 同一概念只使用一个术语；首次出现缩写时给出全称。
- 标题使用阿拉伯数字分级，不在标题结尾使用标点。
- 表格用于多对象的固定字段比较；流程关系使用图而不是长段落。
- 图前说明为什么需要该图，图后说明关键关系和结论。
- 使用“应”“不得”“可以”准确区分强制、禁止和可选要求。
- 避免“先进、领先、全面、高效”等没有衡量标准的形容词。
- 避免大段复述需求，重点说明需求如何被设计满足。
- 指定模板时，以 `模板蒸馏规范.md` 的页面、字体、标题、表格和题注为权威。
- 所有正式标题使用真实 Heading 样式，标题层级连续；不要用加粗正文模拟标题。
- 正文中文字体必须在生成和渲染环境中可用，发现方框或缺字时替换字体并重新渲染全部页面。
- 架构图、业务流程图、数据流程图和时序图使用统一命名、颜色和题注，图片不超出正文宽度。
- Word 图题承担图名，图内不重复中文标题、英文眉题或底部备注。
- 连线从图块间隙或外围通道通过，不穿越图块；可使用圆点、虚线和步骤编号表达方向。
- 按 Word 实际嵌入尺寸检查字体可读性，同时保留可维护源图和交付图片，并设置准确替代文本。
- 表格设置明确表头；长表重复首行；不要用缩小到不可读的字体容纳宽表。
