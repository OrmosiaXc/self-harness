# 完整阶段流程

| 阶段 | 输入 | Agent 产物 | 默认停顿条件 |
|---|---|---|---|
| 已创建 | 文档名称 | 标准工作区、长任务计划、会话交接 | 等待资料 |
| 资料已识别 | 任务说明、投递资料、外部路径索引 | 资料使用清单、冲突缺失表、源码与材料理解台账、参考样本蒸馏规范 | 关键冲突 |
| 模板已蒸馏 | 指定 Word 模板 | 模板蒸馏规范、参考渲染 | 模板无法解析或方向冲突 |
| 提纲待确认 | 资料清单、台账、合同追踪 | 当前提纲、章节骨架 | 等待一次确认 |
| 编写中 | 已确认提纲 | 独立章节、分章预览、图表、问题、追踪矩阵、检查点 | 无 |
| 评审中 | 全部章节 | 质量报告、修订计划 | 错误级问题 |
| 待交付 | 已通过检查的章节 | 预览稿 | 用户确认 |
| Word 质检中 | DOCX | 结构报告、全部页面图片、修复记录 | 逐页检查未完成 |
| 已完成 | 确认稿、模板、质检证据 | Markdown、DOCX、图表、质量报告 | 无 |

每次状态变化都更新 `00-任务说明/当前状态.md`、`长任务计划.md`、`会话交接.md` 和 `.agent/state.json`。机器状态以 JSON 为准，面向用户的中文文件用于查看和跨会话恢复。
