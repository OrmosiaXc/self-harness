# Word 模板蒸馏与全页质检

## 模板蒸馏

指定模板是版式权威，不是项目事实来源。保持原模板只读，在工作区 `.agent/template-audit/` 或系统临时目录中完成分析。

### 必须提取

- 文件哈希、页数和分节；
- 纸张、方向、页边距、页眉页脚距离；
- 封面视觉、标题位置、版本表和前置页顺序；
- 正文、一级至五级标题、题注、页眉页脚的字体、字号、间距和缩进；
- 标题是否使用真实 Heading 样式；
- 自动编号、目录、页码和交叉引用；
- 表头颜色、边框、单元格边距、重复首行；
- 图片数量、行内/浮动方式、宽度、题注和清晰度；
- 字体缺失、旧目录字段、伪标题、浮动对象和渲染差异风险；
- 模板反映的章节篇幅比例。

将结果写入 `02-资料识别/模板蒸馏规范.md`，正文生成器和人工修订都以该文件为准。

## 生成规则

- 使用真实 Heading 样式，不用正文样式模拟标题。
- 指定模板的字体在当前环境缺失时，选择可稳定渲染的中文字体，并在蒸馏规范中记录替代。
- 封面、修订记录、编制说明、目录、正文和附录使用明确分节。
- 表格设置表头、重复首行、可读字号和单元格留白。
- 图形以行内图片为主，宽度不超过正文区域；图前说明用途，图后解释结论。
- 架构图、业务流程图、数据流程图和关键时序图必须与正文名称一致。
- 清理作者、批注、修订、隐藏文本、外部关系和无关自定义属性。

## Word 质量流程

1. 修改或替换已有 DOCX 前运行 `agent.py preflight-word`，检查可读写性、应用占用、包结构和 macOS 文件保护属性；预检不自动解除保护。
2. 生成 DOCX。
3. 检查 DOCX 压缩包、核心 XML、标题、表格、图片、字段、外部关系、修订、隐藏文本、本机路径、内部产物和参考样本禁用词。
4. 使用 `agent.py qa` 渲染全部页面并生成页面图片。
5. 长文档生成联系表或分批检查全部页面。
6. 逐页检查并记录：
   - 中文缺字或方框；
   - 标题孤立或层级错误；
   - 文本、表格和图片溢出或截断；
   - 图题、表题和交叉引用错误；
   - 意外空白页、过度稀疏页或段落异常跳页；
   - 目录、页码、页眉页脚错误；
   - 图片模糊、变形或超出边距；
   - 图内重复标题、英文眉题、底部备注、连线穿块、字体过小或替代文本缺失；
   - 敏感信息和未清理元数据。
7. 修复后重新生成并全量渲染，不只检查修改页。
8. 逐页检查通过后运行 `agent.py qa --confirm-visual`。

## 完成标准

以下任一情况存在时不得交付：

- 只验证 DOCX 能打开，没有渲染；
- 只抽查首页和目录，没有检查正文全部页面；
- 指定模板未蒸馏或原模板被修改；
- 正式目录缺章、页码错误或标题不是结构化样式；
- 文档含批注、修订、占位符、敏感配置或无关附件。
