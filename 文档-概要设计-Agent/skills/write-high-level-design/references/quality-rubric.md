# 质量评分规则

正式交付前按每项 0 至 2 分评估，错误级问题必须清零。

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 完整性 | 关键章节缺失 | 有章节但内容薄弱 | 章节和关键主题完整 |
| 正确性 | 存在无依据事实 | 部分结论待确认 | 事实和结论均可追溯 |
| 一致性 | 名称、图文或边界冲突 | 少量不一致 | 术语、图、接口和部署一致 |
| 可追踪性 | 无来源和需求映射 | 部分可追踪 | 需求到设计和章节完整映射 |
| 可实施性 | 无法指导后续设计 | 主要方案明确 | 边界、协作、异常和约束清晰 |
| 可验证性 | 质量要求不可测 | 部分有指标 | 质量目标有机制和验证方法 |
| 可维护性 | 单一巨型文档 | 有章节拆分 | 章节、图、决策和版本独立维护 |
| 内容深度 | 叶子小节只有概括或套话 | 部分小节展开不足 | 内容符合章节职责且无机械重复 |
| 证据边界 | 合同、源码和目标设计混写 | 部分标识状态 | 证据状态清晰且措辞一致 |
| 内容安全 | 含本机路径、样本事实或未授权依赖说明 | 存在文件名、资料编号、内部标识或代码类名 | 参考材料有效内容已吸收，且无载体和内部产物泄漏 |
| 模板符合度 | 未使用指定模板 | 基本套用但未蒸馏 | 样式蒸馏、结构化标题和版式一致 |
| Word 质量 | 仅能打开 | 抽样渲染 | 全页渲染、逐页检查并修复 |

错误示例：强制要求冲突、合同功能遗漏、项目事实无来源、模块边界互斥、叶子小节一节一段、重复套话、本机路径、资料编号、未授权的参考文件名或样本事实泄漏、正式版含未接受占位符、指定模板未使用、源码目录被写入、技术类概要设计混入库表字段或部署操作、DOCX 未完成全页检查。
