# 使用示例

用户：`新建概要设计文档，名称为“统一业务平台概要设计”`。

Agent 创建 `workspaces/统一业务平台概要设计/`，提示用户填写任务说明并投递资料。

用户：`资料已经放好，请整理并生成提纲。`

Agent 识别资料用途，生成资料使用清单、参考样本蒸馏规范、冲突缺失表、当前提纲和独立章节骨架。

用户：`提纲确认，开始编写。`

Agent 逐章生成内容并维护章节索引、问题与假设和需求追踪矩阵。

用户：`先生成第三章 Word 预览，我要逐章查看，不要合并总文档。`

Agent 将单章 Markdown 和 DOCX 写入 `03-过程成果/08-分章预览/`，正式总稿保持不变。

用户将修改意见写入 `04-调整意见/调整要求.md` 后说：`应用本轮调整。`

Agent 创建快照、记录章节哈希、分析影响范围，只修订相关章节并在范围检查通过后归档调整。

用户：`生成正式交付版。`

Agent 执行 final 质量检查，错误清零后在 `05-交付成果/02-正式版/` 生成 Markdown 和 DOCX。
