# 公共资源库说明

公共资源库保存跨项目长期有效的企业规则和通用参考，由资源管理员维护。具体项目的需求、合同、接口表、会议纪要和历史设计文档不得放在这里，应放入对应工作区的资料投递目录。

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| 01-企业编写规范 | 公司批准的写作、评审、命名规则 | 某个项目的临时要求 |
| 02-标准章节模板 | 每章的目的、必写项和检查项 | 已写好的具体项目正文 |
| 03-通用内容参考 | 跨项目可复用的设计说明方法 | 未核验的项目事实 |
| 04-样式规范 | 字体、标题、表格、图注、术语风格 | 当前项目原始资料 |
| 05-正式交付模板 | 企业统一 Word 参考模板 | 仅供阅读的历史样例 |
| 06-术语与缩写 | 企业统一术语、系统名和缩写 | 临时口头称呼 |
| 07-外部标准 | 标准名称、版本和适用范围 | 大量无筛选的标准原文 |
| 08-经验回流 | 经评审、跨项目适用且可验证的 QA 经验 | 项目事实、一次性偏好和其他项目的删除授权 |

更新公共资源后应运行回归案例，确认不会改变已有项目事实或破坏正式输出。
