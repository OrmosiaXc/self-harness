# 经验索引

本索引只保存已评审的通用规则入口，保持简短。项目偏好和项目事实不得进入本目录；当前工作区规则优先于共享经验。

- `QA-001`：叶子小节必须有实质展开，阻止一节一段和重复套话。详见 [章节内容深度](topics/qa-001-章节内容深度.md)。
- `QA-002`：参考样本只蒸馏形式特征，禁止继承项目事实和路径。详见 [参考样本隔离](topics/qa-002-参考样本隔离.md)。
- `QA-003`：逐章预览、限定修订范围，未获指令不主动合并总稿。详见 [分章增量交付](topics/qa-003-分章增量交付.md)。
- `QA-004`：图件采用可维护源图并执行 Word 全页质检。详见 [图件与 Word 质检](topics/qa-004-图件与Word质检.md)。
- `QA-005`：Word 编辑前预检，历史版本默认保留且清理需明确授权。详见 [可编辑性与版本治理](topics/qa-005-可编辑性与版本治理.md)。
