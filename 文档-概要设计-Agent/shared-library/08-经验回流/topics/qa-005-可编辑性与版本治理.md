# QA-005 可编辑性与版本治理

## 编辑前置规则

修改或替换已有 Word 前检查文件是否可读写、是否被 Word/WPS 占用、DOCX 包是否完整，以及是否存在 macOS provenance/quarantine 属性。预检只报告，不自动移除保护属性或关闭应用。

## 版本规则

默认保留历史成果。项目可以配置“只保留当前版”，但删除旧稿仍需用户明确指令，并且只能清理当前工作区内由 Agent 生成的旧稿、临时渲染件和过期快照；原始资料、参考样本、QA 记录和其他项目不在清理范围内。

## 验证

替换前预检无错误；正式目录只有用户认可的当前版本；任何清理动作都有明确目标清单和授权。
