# QA-002 参考样本隔离

## 触发信号

- 用户要求参照另一份文档的篇幅、格式或图片方式；
- 样本项目名称、业务内容、指标或本地路径混入当前文档。

## 通用规则

先蒸馏样本页数、标题分布、正文段落密度、表格数量、图件数量和章节展开方式。只继承形式特征；当前项目合同、需求、源码证据和用户指令决定事实。将样本项目名称和旧系统名称登记为禁用词。

将“材料内容”与“材料载体”分开：当前项目材料中已验证的实际内容可以进入正文，但文件名、资料编号、本地路径和编写依赖说明默认不进入正式交付物。逻辑依赖说明只在用户明确要求后启用，且不自动允许绝对路径。

## 验证

参考样本保持只读且哈希不变；正式 Markdown、DOCX、元数据和图片替代文本中的禁用词、本地路径、资料编号和未授权参考文件名扫描为零。
