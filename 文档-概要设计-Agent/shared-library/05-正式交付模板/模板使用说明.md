# 正式交付模板使用说明

这里存放企业长期使用的 Word 参考模板。某个项目临时指定的模板应放在项目工作区的 `01-资料投递/指定交付模板放这里/`。

通用渲染器将 Word 文件作为 Pandoc reference document 使用，继承页面、字体、标题、表格等样式。若指定模板包含必须保留的固定封面、审批表、域代码或内容占位符，应由 Agent 使用 DOCX 编辑能力在原模板基础上填充，不能只作为样式参考文档处理。

使用指定模板前必须生成 `模板蒸馏规范.md`，记录模板哈希、分节、页面、字体、标题、表格、目录、页码、图形和篇幅。原模板保持只读。

正式 DOCX 生成后运行 `agent.py qa` 渲染全部页面。只验证文件能打开或只抽查首页不算完成；逐页检查通过后再使用 `--confirm-visual` 固化结论。
