# 新建与编写流程

1. 运行 `python3 agent.py new "文档名称"`。
2. 引导用户填写 `编写任务.md`、成果目录和章节配置；普通资料放投递目录，外部合同、模板或源码路径写入 `外部资料与源码索引.md`。
3. 运行 `python3 agent.py inspect "文档名称"`，生成资料使用清单、机器清单和参考样本蒸馏规范。
4. 按资料索引逐项阅读合同、详细设计、模板和源码，更新 `源码与材料理解台账.md`；代码目录保持只读。
5. 对内容、目录和样式参考只蒸馏标题、段落、表格、图件和篇幅特征；对指定交付模板执行结构解析和参考渲染。
6. 建立合同/需求追踪编码，保证强制功能只增不减；记录冲突、缺失和证据状态。
7. 运行 `python3 agent.py outline "文档名称"`，根据章节配置生成标准骨架，再结合合同和系统实际细化。
8. 等待用户确认目录，或按调整意见更新目录。
9. 逐章编写正文；每章写明事实依据、设计结论、业务到技术实现、数据接口、异常边界和待确认项；叶子小节不得只有一段概括或重复套话。
10. 系统概要设计按全部功能点逐项展开，至少覆盖模块概述、功能架构、功能逻辑、业务流程、技术实现、数据与接口、异常与边界。
11. 更新章节索引、问题与假设、需求追踪矩阵、长任务计划和会话交接。
12. 运行结构质量检查；需要逐章审阅时运行 `render-chapter`，不自动合并总文档；重要阶段使用 `python3 agent.py checkpoint` 固化进度。
13. 用户确认后运行 final 检查和正式版渲染。
14. 运行 `python3 agent.py qa "文档名称"`，检查渲染页并修复；逐页检查完成后运行 `--confirm-visual`。
