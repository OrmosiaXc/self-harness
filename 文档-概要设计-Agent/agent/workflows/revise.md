# 调整与修订流程

1. 读取 `04-调整意见/调整要求.md` 和新增资料。
2. 运行 `python3 agent.py revise-plan "文档名称"` 生成影响分析。
3. 修订前在 `.agent/snapshots/` 保存受影响文件快照，并记录全部章节哈希。
4. 只修改影响分析列出的章节；结构调整时同步更新提纲和章节索引。
5. 同步更新源码与材料理解台账、问题与假设、追踪矩阵、质量报告和长任务检查点。
6. 若调整影响模板、目录或图表，重新生成 DOCX 并执行全页渲染检查。
7. 运行 `revise-done` 前比较章节哈希，发现范围外变化时停止归档并先恢复或确认。
8. 清理历史成果仅在用户明确要求时执行，且不得删除原始资料；工作区版本偏好不等于删除授权。
9. 运行 `python3 agent.py revise-done "文档名称" --summary "本轮修改摘要"` 归档本轮意见。
