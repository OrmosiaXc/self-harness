# 长任务计划

| 阶段 | 状态 | 主要产物 | 完成证据 |
|---|---|---|---|
| 1. 任务定义 | in_progress | 制作任务、约束清单 | 受众、范围和确认方式明确 |
| 2. 资料识别 | pending | 资料清单、事实台账 | 关键结论有证据状态 |
| 3. 技术大纲 | pending | 技术大纲、章节边界、页面 ID | 用户确认 |
| 4. 全局契约 | pending | 样式、字体、区域、所有权与 QA 规则 | 契约 locked 并记录版本或哈希 |
| 5. 子章节拆分 | pending | 自包含任务包、调度台账 | 任务范围无重叠、依赖可控 |
| 6. CyberPPT 效果图 | pending | 内容锁、整套效果图、组件签名 | 用户确认或记录无需暂停 |
| 7. 可编辑构建 | pending | 子章节 PPTX、备注、PptxGenJS 源码 | 章节构建和 QA 通过 |
| 8. 父任务集成 | pending | 标题、页码、全局元素、完整 PPTX | 契约和标题映射一致 |
| 9. 全稿质量检查 | pending | PDF、PNG、总览、QA 报告 | 修复复验通过 |
| 10. 交付 | pending | 正式成果、版本记录 | 文件与哈希一致 |
| 11. 旧版清理 | pending | 删除记录 | 新版先验证、用户已授权 |

父任务同一时间只保留一个全局阶段为 `in_progress`。进入子章节构建阶段后，可以并行运行多个独立章节任务，但每个章节内部一次只推进一个页面闭环。
