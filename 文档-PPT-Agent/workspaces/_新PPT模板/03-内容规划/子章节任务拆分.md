## 拆分检查

- [ ] 技术大纲已确认；
- [ ] 页面 ID 已冻结；
- [ ] 章节资料可独立索引；
- [ ] 未解决的跨章节依赖已由父任务保留；
- [ ] 全局构建契约已锁定；
- [ ] 每个子章节任务包自包含；
- [ ] 子章节不再次拆分任务。
