## 规则

- 页面 ID 一经下发保持稳定；
- 最终页码只由父任务更新；
- 标题文本由父任务在集成阶段写入；
- 标题变化影响内容结构时，必须同步更新内容锁并退回受影响章节；
- 每个页面 ID 只能对应一个子章节交付页。
