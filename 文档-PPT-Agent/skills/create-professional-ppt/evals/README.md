# Skill 评估说明

`evals.json` 包含三类代表性任务：

1. 文档与截图生成领导验收汇报，并要求先目录、后风格、再 PPTX；
2. 从实际 Python 代码重写局部技术页，并要求领导易懂和新版后清理旧版；
3. 从 DOCX/PDF 直接生成严谨可编辑 PPT，不暂停风格预览。

首版完成了一项轻量“使用 Skill / 不使用 Skill”对照：

| 配置 | 通过项 | 总项 | 通过率 |
|---|---:|---:|---:|
| 使用 Skill | 6 | 6 | 100% |
| 不使用 Skill | 4 | 6 | 66.67% |

Skill 的主要增益是明确要求每页演讲者备注，以及至少一次“发现问题—修复—重新渲染—复验”闭环。

该评估只比较方案行为，不代表真实 PPT 的视觉质量。实际项目仍需完成完整构建和渲染 QA。
