# 标题留白的内容页集成模式

## 模式定义

`content-only-integration` 用于多个章节分别生成页面、最后由父任务统一合并的场景。子章节生成完整 16:9 页面，但只在内容区放置对象；标题区保持空白，标题、页码和全局页眉页脚由父任务在集成阶段添加。

这不是裁剪画布，也不是删除标题后扩大正文。标题保留区必须在视觉和坐标上真实存在。

## 页面区域

全局构建契约必须用英寸明确：

- `title_zone`：父任务拥有，子章节不得放置可见对象；
- `content_zone`：子章节唯一可构建区域；
- `footer_zone`：若启用，由父任务拥有，子章节不得写页码、来源或总结；
- `safe_margin`：所有页面共同遵守。

默认仅作建议，项目必须显式确认：

```yaml
zones:
  title_zone: {x: 0.60, y: 0.30, w: 12.13, h: 0.85, owner: parent}
  content_zone: {x: 0.60, y: 1.30, w: 12.13, h: 5.65, owner: chapter}
  footer_zone: {x: 0.60, y: 7.05, w: 12.13, h: 0.20, owner: parent}
```

若最终母版没有页脚，可将 `footer_zone.enabled` 设为 `false`，但不能由子章节自行决定。

## 效果图规则

- 效果图使用完整页面比例，显示空白标题区和真实内容区；
- 不在标题区放章节名、临时标题、装饰线、角标或水印；
- 不显示页码、底部总结、`So What`、来源栏或内部构建提示，除非全局契约明确由子章节承担；
- 页面标题保存在独立映射文件，不以文件名或聊天记录作为唯一来源；
- 视觉重心仍需稳定，不能因标题留白而把主体上移占满。

## 可编辑 PPTX 规则

- 页面尺寸保持目标母版尺寸；
- 子章节不得创建可见标题、页码、页眉或页脚对象；
- 内容对象的边界必须完全位于 `content_zone`；
- 背景色优先使用幻灯片背景属性，避免用覆盖标题区的整页形状；
- 每页至少包含可编辑文本和足够的原生对象；
- 备注中使用稳定页面 ID，而不是依赖尚未确定的最终页码；
- 构建时使用内容区坐标，不在集成时缩放整页适配。

## 页面标题映射

父任务维护 `页面标题映射.md`，至少记录：

- 稳定页面 ID；
- 章节 ID 和章节内顺序；
- 最终页码；
- 页面标题和可选副标题；
- 标题样式 token；
- 子章节 PPTX 和页面清单位置；
- 集成状态。

标题变更只更新映射和父任务集成层；只有标题变化影响内容结构时，才退回子章节重建。

## 合并规则

1. 父任务验证子章节 PPTX 的画布、契约版本、页面 ID 和标题保留区。
2. 按页面标题映射排序导入页面，不以文件系统自然顺序推断页码。
3. 不缩放、截图或栅格化子章节页面；保持原生对象和备注。
4. 在父任务层添加标题、章节标识、页码及全局页眉页脚。
5. 对全稿执行结构检查、跨章节一致性检查和完整渲染。
6. 若发现标题与正文碰撞，优先修正全局区域或标题样式；不得临时压缩单页正文掩盖问题。

## 验收点

- 所有子章节页面的标题保留区为空；
- 内容对象未侵入标题区或父任务页脚区；
- 页面 ID 与标题映射一一对应；
- 合并后标题文字、位置、字体和层级全稿一致；
- 合并过程未产生整页图片、字体替换、对象漂移或备注丢失；
- 单章节 QA 和全稿集成 QA 均通过。
