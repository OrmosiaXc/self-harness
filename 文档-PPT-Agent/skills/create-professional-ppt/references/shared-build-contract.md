# 全局构建契约

## 定位

全局构建契约是父任务向所有子章节下发的唯一共享标准。它同时约束效果图、可编辑构建和最终集成，避免不同任务各自理解“统一风格”。

契约在子章节任务开始前冻结，并具有版本号。项目特有的品牌色、字体、母版和单位名称只保存在项目契约中，不写入通用 Skill。

## 必填内容

### 画布和区域

- 页面比例、宽高和安全边距；
- 标题区、内容区、页脚区的坐标和所有者；
- 标题留白模式、母版接入方式和禁止侵入区域。

### 视觉 token

- 中文与英文字体、回退字体；
- 标题、正文、注释、数字和图表标签字号；
- 主色、辅助色、强调色、状态色和中性色；
- 线宽、圆角、阴影、卡片内边距、列间距和网格；
- 图标来源、线性/填充风格和最小尺寸。

### 组件规则

- 结论卡、流程、架构、时间线、矩阵、表格和图表的结构；
- 数值单位、图例、来源和边界的呈现方式；
- 页面密度上限、长文本压缩顺序和禁止组件；
- 截图、照片、SVG 和位图的使用边界。

### 内容和所有权

- 父任务拥有：技术大纲、标题映射、全局标题、页码、页眉页脚、章节过渡和最终整合；
- 子章节拥有：章节资料、事实台账、逐页内容锁、效果图、可编辑内容对象和章节 QA；
- 共享但不可私改：受众、术语、色板、字体、页面区域、组件规则和质量门。

### 构建与 QA

- 效果图分辨率、命名、确认状态和组件签名；
- PptxGenJS 版本、字体环境、对象命名和备注格式；
- 结构检查、标题保留区检查、渲染、对照和修复复验；
- 交付目录、文件命名、版本、哈希和集成顺序。

## 继承与偏差

子章节任务启动时复制只读契约快照，并记录版本或 SHA-256。以下内容不得自行改变：

- 画布和区域坐标；
- 主字体与回退顺序；
- 颜色 token 的值和语义；
- 标题、正文和注释层级；
- 全局组件的几何和样式；
- 标题、页码和页眉页脚所有权；
- 质量门和交付清单。

确有业务需要时提交偏差申请，说明原因、受影响页、建议值和回归范围。只有父任务更新契约并同步所有受影响章节后，偏差才生效。

## 冻结顺序

1. 技术大纲确认；
2. 视觉方向确认；
3. 页面区域和所有权确认；
4. 全局构建契约标记为 `locked`；
5. 生成契约版本或哈希；
6. 下发子章节任务包。
