# PPT Agent：从这里开始

把本目录作为 Codex 工作区打开，然后直接说：

> 新建一份 PPT，名称为“某项目验收汇报”。先分析资料并生成技术大纲和逐页目录；确认后锁定统一样式，再用 CyberPPT 生成整套效果图，最后按子章节构建可编辑内容页，标题区留空供父任务统一合并。

## 最简流程

1. 对 Agent 说：`新建 PPT，名称为“某项目验收汇报”`。
2. 在 `workspaces/某项目验收汇报/00-任务说明/制作任务.md` 填写用途、受众、页数、风格、必须包含和必须删除的内容。
3. 把资料放入 `01-资料投递/所有参考资料放这里/`；外部文档或源码保持原位时，把绝对路径登记到 `外部资料与源码索引.md`。
4. 让 Agent 先完成资料识别和事实台账，再生成 `技术大纲.md`、`PPT逐页内容目录.md` 和 `页面标题映射.md`。
5. 在 `目录确认记录.md` 确认章节、页数、页面 ID 和逐页内容。
6. 填写并锁定 `00-任务说明/全局构建契约.yaml`，统一画布、标题区、字体、色板、网格、组件和 QA。
7. 需要并行时明确说“按子章节创建任务会话并行构建”；父任务生成自包含任务包并登记到调度台账。
8. 让 Agent 用 CyberPPT 先做风格样张，再生成整套效果图，在 `04-视觉预览/确认记录.md` 确认。
9. 让每个子章节用 PptxGenJS 构建可编辑内容页。`content-only-integration` 模式下标题区必须留空。
10. 父任务验收章节交付，按标题映射合并并统一添加标题、页码和全局页眉页脚。
11. 查看 `06-质量检查/父任务集成验收.md`、视觉 QA 和结构验证报告。
12. 需要调整时只写 `08-调整意见/调整要求.md`；Agent 应局部修改、重新验证并登记版本。
13. 确认后从 `07-交付成果/正式版/` 获取 PPTX、脚本、资源和报告。

## 三个硬确认点

- 内容确认：章节、页数、每页结论、证据、视觉建议和汇报口径。
- 全局契约确认：标题与内容区域、配色、字体、网格、卡片/流程/图表和父子任务所有权。
- 效果图确认：代表页风格和整套 CyberPPT 页面效果。

用户没有要求中途确认时，Agent 可连续推进，但仍需在工作区保存三个阶段的决策记录。
