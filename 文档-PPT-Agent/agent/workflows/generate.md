# 生成工作流

## 父任务阶段

1. 初始化工作区、状态和制作任务，选择 `full-slide` 或 `content-only-integration`。
2. 识别资料类型、用途、可信度和冲突，建立事实与证据台账。
3. 形成技术大纲、章节边界、稳定页面 ID、逐页内容目录和页面标题映射。
4. 完成内容确认。
5. 生成全局构建契约，锁定画布、标题区、内容区、字体、色板、网格、组件、所有权和 QA 标准。
6. 用户明确启用任务会话拆分时，按子章节创建自包含任务包和独立目录；否则按相同任务包顺序执行。

## 子章节阶段

7. 每个子章节独立建立资料索引、事实台账、内容锁和页面清单。
8. 使用 CyberPPT 生成代表页和整套效果图；标题留白模式只绘制内容区。
9. 父任务汇总效果图并完成视觉确认。
10. 每个子章节按页顺序用 PptxGenJS 重建原生可编辑对象和演讲者备注。
11. 逐页执行内容锁校验、效果图对照、结构检查、渲染、修复和复验。
12. 生成子章节交付清单并提交父任务验收。

## 集成与交付阶段

13. 父任务验证契约版本、页面 ID、标题保留区、内容零漂移、视觉语义和可编辑性。
14. 按页面标题映射合并，统一添加标题、章节标识、页码和全局页眉页脚。
15. 执行全稿结构验证、PDF/PNG 渲染、跨章节一致性检查和至少一次修复复验。
16. 生成交付说明、版本记录和哈希。
17. 如用户明确要求，验证新版后清理精确列出的旧版。

## 并行边界

- 父任务同一时间只推进一个全局阶段；
- 子章节构建阶段可并行，但每个子章节内部逐页顺序构建；
- 子章节不再次拆分任务，不修改全局契约和其他章节；
- 所有共享变更由父任务写入磁盘、提升契约版本并广播。
