# 事实与证据策略

## 事实状态

- 已验证事实：可直接追溯到合同、正式文档、数据、运行结果、测试记录或实际源码。
- 文档陈述：来源文档如此描述，但尚未通过实现或结果核对。
- 源码现状：实际调用链、输入、输出、算法和异常逻辑。
- 目标表达：为了汇报而组织的概括，不等同于新增事实。
- 待确认：资料冲突、缺失或需要业务判断的内容。

## 使用规则

1. 页面核心结论必须能指向来源或明确边界。
2. README 和注释只能作为线索；代码任务必须核对入口、调用链和实际输出。
3. 不从界面截图反推算法效果或验收结论。
4. 不以示意图代替真实测试数据。
5. 证据冲突时保留冲突，不擅自选择有利版本。
