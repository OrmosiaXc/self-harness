# PPT Agent 使用说明

这个 Agent 帮你把项目资料整理成可编辑的 PowerPoint，包括内容规划、页面设计、PPTX 制作、检查和交付。普通使用者主要操作 `workspaces/你的PPT名称/`，不需要编辑 `agent/`、`skills/` 或 `config/`。

## 目录是做什么的

每创建一份 PPT，会生成一个工作区：`workspaces/<PPT名称>/`。

| 工作区目录 | 用途 | 你通常要做什么 |
|---|---|---|
| `00-任务说明/` | PPT 名称、受众、场景、页数、内容要求、制作模式和确认状态。 | 填写 `制作任务.md`；查看当前状态、计划和交接。 |
| `01-资料投递/` | PPT 要使用的报告、Word、PDF、图片、数据和源码索引。 | 放参考资料，或登记外部资料路径。源码目录保持原位。 |
| `02-资料识别/` | Agent 记录资料用途、事实、证据及冲突/缺失。 | 检查关键结论是否有可靠依据。 |
| `03-内容规划/` | 技术大纲、逐页内容目录、页面标题映射和章节拆分。 | 确认“讲什么、按什么顺序讲、每页的核心结论”。 |
| `04-视觉预览/` | 风格说明、效果图和视觉确认记录。 | 查看效果图并确认整体视觉方向。 |
| `05-构建工程/` | PPTX 的脚本、素材、章节文件和依赖。 | 通常由 Agent 维护；需要时可查看或交给开发者。 |
| `06-质量检查/` | PPTX 结构报告、渲染图、视觉 QA 和集成验收。 | 查看检查报告和逐页预览。 |
| `07-交付成果/` | 最终 PPT、交付说明及相关正式文件。 | 从 `正式版/` 获取交付物。 |
| `08-调整意见/` | 本轮需要修改的页面和要求。 | 写清要改哪些页、怎么改、依据是什么。 |
| `.agent/` | Agent 自动保存的机器状态。 | 一般不用打开或修改。 |

## 开始使用

在支持项目指令和文件操作的智能开发工具中打开本目录，直接告诉 Agent：

> 新建一份 PPT，名称为“项目验收汇报”。请先梳理资料并列出逐页目录，确认内容后再做视觉预览和可编辑 PPT。

也可以在命令行新建工作区：

```bash
python3 agent.py new "项目验收汇报"
```

新建后填写 `00-任务说明/制作任务.md`，并把资料放进 `01-资料投递/所有参考资料放这里/`。若代码或资料留在原目录，把位置登记到 `01-资料投递/外部资料与源码索引.md`。

## 提示词和使用案例

这些是可以直接发给 Agent 的自然语言指令，不需要使用特殊标签。

| 想做什么 | 提示词案例 |
|---|---|
| 新建 PPT | `新建一份 PPT，名称为“智慧园区验收汇报”，面向验收专家，约20页。先分析资料并提出逐页目录，等我确认后再继续。` |
| 登记或补充资料 | `我已把资料放入 workspaces/智慧园区验收汇报/01-资料投递，请逐项阅读并更新事实与证据台账；源码只读。` |
| 生成/调整大纲 | `请根据已登记资料生成技术大纲、逐页内容目录和页面标题映射，标出每页结论、来源和建议图表，先不要生成PPTX。` |
| 确认内容目录 | `我确认当前技术大纲和逐页内容目录，按这个版本继续。` |
| 确认视觉风格 | `我确认04-视觉预览中的效果图风格，请按当前全局构建契约制作可编辑页面。` |
| 选择构建模式 | `这份PPT后续要按章节合并，请使用 content-only-integration，子章节只做内容区，标题留白由父任务统一添加。` |
| 启用章节并行 | `请按章节拆分任务会话并行制作。先锁定全局构建契约，再生成每个章节独立的任务包。` |
| 顺序制作不拆会话 | `请在当前工作区顺序完成所有章节，不要创建独立任务会话。` |
| 调整已完成页面 | `请只修改第8页：把现状和目标改成左右对照，保留原结论。更新调整记录，并重新渲染检查该页和相邻页。` |
| 查看进度 | `请读取当前状态、长任务计划和章节调度台账，告诉我完成到哪一步、下一步是什么。` |
| 检查并交付 | `请完成全稿结构检查和逐页渲染，修复发现的问题后复验，再整理正式版、构建脚本、资源和QA报告。` |

## 一份 PPT 的制作顺序

```text
写清任务 → 投递资料 → 核对事实 → 确认逐页目录 → 确认统一样式
→ 查看效果图 → 制作可编辑PPT → 检查修复 → 获取正式版
```

1. **先确认内容**：每页讲一个重点，关键结论有来源；没有依据的数据要标成待确认，不要当作事实。
2. **再确认样式**：全局构建契约记录画布、字体、色彩、页面区域和统一元素。
3. **查看视觉预览**：效果图用于确认页面设计，之后 Agent 会用 PowerPoint 原生文字、形状和图表重建页面，确保内容可编辑。
4. **制作和检查**：检查 PPTX 结构，并渲染 PDF、逐页图片和总览图；发现问题后修复并复验。
5. **交付**：从 `07-交付成果/正式版/` 取 PPTX，并查看交付说明和质量报告。

`full-slide` 表示当前任务制作完整页面。`content-only-integration` 表示子章节只做页面内容区域，标题和页脚由父任务合并。是否拆分并行任务会话需要明确提出；不说并行时通常顺序处理。

## 常用命令

```bash
python3 agent.py --help
python3 agent.py new "项目验收汇报"
python3 agent.py status "workspaces/项目验收汇报"
python3 agent.py validate-workspace "workspaces/项目验收汇报"
python3 agent.py validate-agent
```
