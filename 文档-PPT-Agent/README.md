# 文档-PPT-Agent

这是一个用于制作专业、严谨、可编辑 PowerPoint 的通用 Agent 工程，适合项目验收、领导汇报、技术评审、建设成果汇报和正式交付。

它把 PPT 制作拆成可确认、可回退、可验证的阶段：

1. 资料与源码事实核对；
2. 技术大纲、章节边界和稳定页面 ID；
3. 全局构建契约和子章节任务拆分；
4. CyberPPT 整套效果图确认；
5. 子章节原生可编辑 PPTX 构建；
6. 父任务统一标题、页码和全局元素集成；
7. 结构检查、完整渲染与视觉修复；
8. 版本交付和旧版安全清理。

核心运行能力位于 `skills/create-professional-ppt/`。普通使用者只需操作 `workspaces/<PPT名称>/`，不需要理解 Agent 内部实现。

## 命令入口

```bash
python3 agent.py new "某项目验收汇报"
python3 agent.py validate-workspace "workspaces/某项目验收汇报"
python3 agent.py status "workspaces/某项目验收汇报"
python3 agent.py validate-agent
./init.sh --full
```

## 适用原则

- 需要先确认逐页目录、再确认视觉风格的长任务；
- 需要从 Word、PDF、Markdown、旧 PPT、图片、数据或源码生成 PPT；
- 需要将技术实现转为领导和验收专家易于理解的表达；
- 需要保持文本、框体、图表和流程可编辑；
- 需要按技术大纲拆成多个任务会话并行开发，同时保证字体、色板、网格和页面结构一致；
- 需要子章节页面保留标题空位、仅构建内容区，后续由父任务合并；
- 需要输出构建脚本、资源依赖、渲染结果和 QA 报告；
- 需要在新版通过验证后清理被替代旧版。

最简用法见 `START-HERE.md`。

## 两种构建模式

- `full-slide`：同一任务生成含标题和全局元素的完整页面。
- `content-only-integration`：子章节输出完整 16:9 的可合并页面，但标题区留空，只构建内容区；父任务统一添加标题、页码和页眉页脚。

品牌色、字体和母版不是通用硬编码。它们写入每个项目的 `00-任务说明/全局构建契约.yaml`，由父任务一次下发给所有子章节。
