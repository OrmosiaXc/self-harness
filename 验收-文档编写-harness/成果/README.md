## 命名及同步

有正式清单时使用“清单序号-文档名称-DOC-编号.docx”，序号至少两位，按实际清单长度扩展；序号与DOC编号不同，不因缺项或排除项重排。无正式序号时使用“文档名称-DOC-编号.docx”。用户指定其他文件编码规则时登记后统一应用。不带内部D/F/STYLE、日期或最终版后缀。

同步依次：持成果/.同步.lock系统锁→重读清单及当前稿→核验用户/其他会话是否修改→复制已复核新稿到临时文件并核对源副本哈希→原子替换本DOC固定文件→局部更新清单→核对后移除本DOC被替代副本。失败保留可恢复稿并登记环节，不删除原始材料或其他DOC成果，不删除锁文件。修订未通过时保留上一份可用成果。
