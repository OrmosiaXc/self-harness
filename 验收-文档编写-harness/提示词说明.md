# 提示词说明

示例只供复制，不自动触发任务。实际标签定义见[README](README.md#标签指令)。编号、路径和版本以本项目台账为准。

## 初始化新项目

```text
请根据当前harness初始化本项目，登记项目身份、系统范围、实际交付清单、原始资料及格式模板，不预建未选定文档。梳理需确认的格式和事实，保留原始代码材料只读。
```

## 新文档：登记资料及启动

```text
知识# /实际项目或材料绝对路径，用途说明
需求# 文档名称、读者、范围和章节要求，请返回XQ及FA编号
方案# XQ-实际编号
```

需要独立会话时明确说“为这些指定文档分别创建独立会话，先大纲确认后逐章编写，继承当前共性规范”。已绑定会话复用，不重复创建。

## 新文档：确认与执行

```text
调整# 当前大纲，说明具体修改内容
确认# FA-实际编号 O实际版本 并执行全部章节
```

只确认时不写“并执行”；执行可限定当前已确认章标题或CH编号。结构变更后确认新O。已有Word的定向修订直接提出内容，不重复确认未改变的全部目录。

## 复核与交付

合并#仅适用于已有章节源的新文档；现有Word修订直接复核修订稿并交付。

```text
复核# 按当前文档定位检查总分总、内容重复、证据与图表一致、共用事实、内部标识和全套格式，已授权范围内发现问题直接修订
合并# 全章完成后生成Word，最终渲染复核并同步成果唯一最新副本及来源哈希
任务完成# 当前文档
```

完成按规则保存知识及进度；任务完成#及归档任务#同义，核验完成后归档专属会话，用户明确保留时除外；不关闭主会话。材料不齐时明确当前版本交付边界，不宣称全部通过。

## 汇总与跨会话同步

```text
进度# 核对成果目录、台账、最新任务与宿主会话状态，列在编、待确认大纲、待归档及已交付但仍有材料缺口
请将最新共性规范同步给当前在编文档会话，按各自文档定位复核调整，完成后更新成果
```

自然语言授权同样有效。跨会话发送须有用户明确授权；不自动重启已归档文档。规则沉淀只更新模板/规范，不自动修改全部已有Word。

## 现有Word定向补充与调整

```text
修订# 文档名称或路径
修改位置：章节、表格或内容。
修改要求：本次需要补充、替换或调整的内容。
依据：已登记资料或本次提供材料。
```

默认在实例所属项目创建或复用文档专属聊天，沿用原稿和上下文格式，保留原稿，交付修订副本及修改摘要，不重列整篇大纲。只要求创建聊天或分析时不修改Word。任务完成#、归档任务#、任务归档#为同义收尾指令；未核实内容如实保留，不自动执行系统测试。
