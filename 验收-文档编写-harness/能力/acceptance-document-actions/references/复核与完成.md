# 章节复核、合并与完成

新文档每章检查对应O的标题和内容覆盖、证据、事实口径、相邻章边界及术语。复核/复核记录.md持续记录CH/C/O、问题、处置、通过/失败/未验证/不适用。章节状态：未开始、编写中、待复核、待修订、已完成、受阻；已完成表示本章约定范围写齐且必需复核通过。

以下合并流程仅适用于有章节源的新文档；现有Word修订直接复核当前修订稿、修改范围、内容差异、上下文格式及最终渲染，不强制合并。

合并前检查所有计划CH完成、当前O确认有效、顺序完整、无重复/缺章、当前C记录准确，前置页和附件齐全。记录合并清单：O、各CH/C及来源路径、F/STYLE、合并D、生成日期、问题和检查证据。按清单读取章节源合并MD，再输出用户所需DOCX/PDF等格式，不另外生成新的整篇正文。

合并时处理章节编号、跨章链接、图表编号、自动目录、统一样式、页眉页脚和分页。格式技能渲染检查整稿，不能以各章节版式通过替代整稿检查。合并发现内容问题回到对应章节修订、递增C后重新生成D。最终稿保留在该DOC/合并/或用户指定位置，按成果规则同步最新副本；归档触发及顺序统一遵循下方完成规则。

新文档普通完成须当前O确认、计划章全部完成、当前合并D及约定复核通过；现有Word修订按本次明确范围、当前修订稿及约定复核核验，不以O/CH为门槛，再登记知识记录并更新知识/README.md和工作台账。文档任务完成不表示项目验收批准。强制完成只记录实际章稿/整稿与跳过项，缺章不得称完整交付，未验证不变为通过。任务完成后按[文档归档与知识复用](文档归档与知识复用.md)生成知识及章节索引、同步工作台账，任务完成#、归档任务#、任务归档#同义，核验收尾后归档绑定专属聊天，用户明确保留时除外。主聊天不归档。
