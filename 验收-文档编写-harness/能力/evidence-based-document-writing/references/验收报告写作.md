# 实施、测试与验收报告写作

用户选择报告类文档时使用，目录优先遵循合同及模板，不套手册功能小节或技术设计五维骨架。

将验收要求对应到交付项、实施活动或用例、环境/版本/日期、真实证据、结果及遗留问题。结论分别说明符合、未符合、未验证或不适用；缺记录、静态代码和历史样本不能写成当前已通过。没有实测规模/性能数据时登记缺口，不制造容量和通过率。

实施报告说明实际部署/迁移/配置范围、步骤、运行观察、回退及移交。测试报告说明目标、范围、环境、用例、实际结果、缺陷处理及覆盖限制；测试计划和预期结果保持独立。验收总结聚合约定交付和可追溯证据，区分文档复核结论、测试结果与需验收方签署的批准，不代用户作批准。

跨文档项目名、角色、版本、模块、接口、用例与缺陷编号一致；变更后标记相关文档待复核。样例里的旧系统名、日期、签字及通过结论不得直接继承。
