# 概要与技术设计写作

本技能专注概要与技术设计内容。配合[通用文档编写](../evidence-based-document-writing/SKILL.md)取证和质检，配合[任务编排](../acceptance-document-actions/SKILL.md)控制大纲确认、章节文件、会话及归档。复用当前项目任务与已登记资料，不另建平行工作区。

输入为目标DOC、需求R、共用事实、已定位证据和当前大纲O；输出为可审阅的大纲建议、需求到设计追踪、按确认O生成的章节以及具体问题记录。大纲未确认时只输出规划。

1. 阅读相关合同/需求、现有设计和实际代码；先确定系统边界、业务角色、外部依赖、数据、模块及差异，区分静态实现和目标设计。
2. 用[设计结构与模块展开](references/设计结构与模块展开.md)形成大纲。采用专项参考中的核心结构，最新用户目录优先，不预设固定章数或专项体系。
3. 逐章说明设计对象、职责、协作、状态异常、验证方式和证据边界。概设保持总体机制，详设按实际任务展开，不根据技能名称自行删除数据库、安全或部署相关有效需求。
4. 采用[设计追踪模板](assets/设计追踪模板.md)组织源要求到章节及验证的映射，嵌入当前任务记录；保留缺失实现和未确定指标。
5. 检查跨体系/模块重复、真实运行单元、业务与数据流程区分、选型理由和适用边界，按通用技能复核内容及图文。

存在其他专项文档时引用其对应内容和版本；只有用户选择这些文档后才建立任务，设计关联不自动新增交付项。
