# 通用验收文档编写 harness

将本模板复制到新项目工作区的harness目录。先登记项目身份、实际交付清单、资料路径与格式规范，再启动用户选定文档；模板不含任何历史项目成果或任务。

| 入口 | 用途 |
|---|---|
| [规则](AGENTS.md) | 工作约束和技能路由 |
| [提示词说明](提示词说明.md) | 可复制的初始化及标签用法 |
| [资料](资料/README.md) | 共用事实、格式、代码材料和文档关系 |
| [能力](能力/README.md) | 编排、取证写作、设计及手册技能 |
| [工作台账](工作台账.md) | 唯一任务、进度及会话状态汇总 |
| [知识](知识/README.md) | 已完成文档摘要与章节检索 |
| [成果](成果/README.md) | 唯一最新Word及来源哈希清单 |

默认流程：需求登记 → 大纲规划 → 用户确认 → 逐章编写复核 → 合并及最终渲染 → 成果同步 → 完成知识登记及授权归档。

任务按需创建：

```text
文档/DOC-编号-名称/
  任务.md
  需求/需求.md
  方案/大纲.md
  执行/章节清单.md
  执行/章节/CH-编号-标题.md
  复核/
  合并/
```

命令脚本、图源或附件仅在当前文档确有需要时创建。初始化不预建空DOC，不复制源项目代码或合同。每个项目保留自己的范围与样式配置；本模板的建议字体和清单不作为该项目合同条款。

## 新项目初始化

1. 将模板复制为目标工作区/harness；工作区已有AGENTS.md时增量加入指向harness/AGENTS.md的入口，不覆盖原规则。
2. 通过知识#登记合同/需求、目录/格式模板、源码、截图和既有文档；读取命中原文并建立索引，不只是保存路径。
3. 在资料/项目.md确认身份、系统/环境、有效交付范围及排除项，保持源序号与DOC编号各自稳定；确认会话和归档偏好。
4. 在资料/编写规范.md确认项目样式。没有专用模板时可明确采用建议基线；未知事实不阻塞大纲规划，但关键格式未定前不声称正式Word复核通过。
5. 仅为选定文档登记需求和编号，生成大纲并确认后逐章编写。模板初始化完成不计文档任务完成。

新项目首次入口可用：`本工作区文档规则见harness/AGENTS.md；共用资料见harness/资料/README.md；任务进度见harness/工作台账.md。`

## 标签指令

使用半角#，编号按工作台账映射。自然语言明确授权同样有效。

| 标签 | 动作 |
|---|---|
| 知识# 路径及用途 | 登记或刷新共用资料，原材料保持原位置 |
| 需求# 文档名称及范围 | 分配DOC、XQ需求编号及FA方案编号 |
| 方案# XQ-编号 | 生成或调整大纲；按用户授权创建/复用独立会话 |
| 修订# 目标Word及要求 | 在所属项目的文档专属聊天中定向补充调整，继承原稿格式，不走新文档大纲流程 |
| 调整# 对象及要求 | 修订明确的目录或章节 |
| 确认# FA-编号 O版本 | 确认大纲；同条“并执行”可授权编写 |
| 执行# 全部章节或指定章 | 在有效确认范围内逐章编写 |
| 复核# 对象 | 内容、证据、格式及渲染检查 |
| 合并# | 全章齐后生成并复核Word，同步成果 |
| 任务完成# / 归档任务# | 同义：核验、归档成果和知识、更新进度并归档专属聊天；用户明确保留时除外 |
| 进度# | 只读核对台账、成果及实际会话状态 |

兼容：编写#＝执行#，测试#＝文档复核#，任务归档#＝归档任务#；强制完成#明确部分交付和未验证项，不把缺项算通过。
